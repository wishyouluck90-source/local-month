# RELEASE FREEZE — v7.3

LOCAL MONTH v7.3 is the pre-public-release feature freeze.

Until the first public URL and iPhone Safari QA are complete:
- Allowed: bug fixes, broken-data fixes, source verification updates, deployment fixes.
- Not allowed: new major feature families, paid APIs, server accounts, payment, destructive data-model rewrites.
- Daily data/status updates remain allowed.

Unfreeze condition:
1. Public static URL returns HTTP 200.
2. iPhone Safari core QA passes.
3. Backup/restore tested on-device.
4. Home-screen PWA launch tested.
